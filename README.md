PART 1: Understanding our project
1.1 Project title
Employee Management System Using Oracle PL/SQL
1.2 Introduction
An Employee Management System is a database application designed to help an organization manage its employees and their information.

In a company, the human resources department needs to store and manage information such as:
- Employee ID.
- First name and last name.
- Email address.
- Phone number.
- Hire date.
- Job title.
- Salary.
- Department.
Managing these records manually can cause errors, duplication, and difficulties when searching for employee information.

Our project will use Oracle Database and PL/SQL to manage employee information efficiently.
1.3 Project objectives
Our system will:
1. Register new employees.
2. Store employee information in database tables.
3. Organize employees according to departments.
4. Retrieve employee records.
5. Update employee salaries.
6. Delete employee records when appropriate.
7. Calculate annual employee salaries.
8. Generate employee reports.
9. Process multiple employee records using bulk processing.
10. Handle database errors using exception handling.
1.4 Main users
User	Responsibility
HR Manager	Manages employee information
HR Officer	Registers and updates employees
Database Administrator	Maintains the database

1.5 System requirements
Functional requirements

These describe what the system must do.
- The system must register employees.
- The system must display employee details.
- The system must update salaries.
- The system must delete employee records.
- The system must calculate annual salaries.
- The system must display employees by department.
Non-functional requirements

These describe how the system should operate.
- The system should protect employee information.
- The database should maintain accurate records.
- The system should handle errors appropriately.
- The system should process large numbers of records efficiently.
